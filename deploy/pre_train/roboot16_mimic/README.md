# Pretrained Policies for Mimic Deploy

This folder stores ONNX policies for the Roboot16 mimic MuJoCo deploy flow.

## Expected File

Typical artifact path:

```text
deploy/pre_train/roboot16_mimic/policy.onnx
```

You may also keep versioned files here such as:

```text
policy1.onnx
policy2.onnx
policy5.onnx
```

## How to Export

The usual workflow is to export from the Isaac Lab mimic play script:

```bash
./isaaclab.sh -p roboot16/scripts/reinforcement_learning/rsl_rl/play.py \
  --task Isaac-Roboot16-Mimic-Project-Play-v0 \
  --checkpoint /path/to/roboot16/logs/rsl_rl/roboot16_mimic_project/<run>/model_<iter>.pt
```

The exported model is written into:

```text
roboot16/logs/rsl_rl/roboot16_mimic_project/<run>/exported/policy.onnx
```

Then copy it here if you want a stable deploy target:

```bash
cp /path/to/roboot16/logs/rsl_rl/roboot16_mimic_project/<run>/exported/policy.onnx \
   /path/to/IsaacLab/roboot16/deploy/pre_train/roboot16_mimic/policy.onnx
```

## Notes

- Mimic deploy expects ONNX metadata generated by the project play/export flow.
- The MuJoCo mimic entry point is `deploy/deploy_mujoco/deploy_mujoco_roboot16_mimic.py`.
